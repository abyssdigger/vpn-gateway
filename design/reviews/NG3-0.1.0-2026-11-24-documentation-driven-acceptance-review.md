## F9 — strict walkthrough found real documentation defects

**Decision:** accepted.  
**Resolution:** fixed and re-executed.

The walkthrough found two defects that the previous mechanism-oriented QA did not expose:

1. the original Debian WireGuard installation command admitted recommended kernel-image
   installation; the publication command now uses `--no-install-recommends`, which is
   sufficient for the already-supported host kernel and executable in the declared evidence
   boundary;
2. the first explicit L2TP service recipe omitted the runtime directory required by
   `xl2tpd-control`; the service now owns `RuntimeDirectory=xl2tpd`.

Both failures occurred while following the published path, were corrected in the documentation
and then passed on re-execution.

This is direct evidence that the acceptance is testing documentation applicability rather than
merely mirroring implementation knowledge.
