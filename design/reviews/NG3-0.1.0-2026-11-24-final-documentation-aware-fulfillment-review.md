## Documentation defects found by the strict walkthrough

The documentation-driven acceptance found two real administrator-procedure defects that the
earlier mechanism-oriented QA had not exposed:

1. the original Debian WireGuard package command allowed recommended kernel-image installation;
   the documented client install now uses `--no-install-recommends`, avoiding an unnecessary
   kernel package while using the already-supported host kernel;
2. the first explicit L2TP service recipe omitted the runtime directory needed by
   `xl2tpd-control`; the documented unit now owns `RuntimeDirectory=xl2tpd`.

Both defects were fixed in the published procedure and the full walkthrough was re-executed to
PASS. This is direct evidence that the documentation acceptance tests operational applicability,
not merely textual correspondence with an internal QA script.
