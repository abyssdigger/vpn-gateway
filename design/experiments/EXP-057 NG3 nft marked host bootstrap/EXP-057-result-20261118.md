The failure is architectural rather than a missing syntax detail: bootstrap classification and
stateful return have different routing semantics. Bootstrap must preserve ordinary routes that
are more specific than the matching Profile destination, while stateful return must force an
already-associated flow back through the managed stack.

Therefore bootstrap and stateful return must not share one undifferentiated mark/table owner.
The selected design keeps stateful return as the EXP-053 owner and gives bootstrap independent
RPDB/table state.
