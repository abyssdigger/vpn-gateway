## Disposition

EXP-074 remains valid lower evidence that the current managed table defeats competing
more-specific routes *inside host table `main`*.

EXP-081 proves that this is not equivalent to the broader normative promise in
`VPNG-U001-R5.R2.R1`: ordinary host routing policy can also act through earlier RPDB rules,
and the current owner neither prevents nor detects that class of bypass.

Therefore the current EXP-074 realization is not sufficient closure for
`VPNG-U001-R5.R2.R1`.

## Design implication

A replacement architecture must make the delegated aggressive scope authoritative relative to
the complete applicable host policy surface, or explicitly detect a policy state that can
precede/bypass its authority and enter a fail-closed path.

The result does not prescribe whether the selected solution is:

- a stronger RPDB ownership contract;
- an independent host filtering/containment layer;
- a composed routing + filtering contract;
- another mechanism with equivalent observable postconditions.
