## Representation correction discovered by the experiment

The first EXP-068 run reached exact probe routing but failed the probe-local readiness gate.
Current Ubuntu 26.04 / nftables 1.1.6 rendered:

```json
{"payload":{"protocol":"ip","field":"protocol"}} == "icmp"
```

where the existing observer accepted only numeric `1`.

The two forms are semantically identical IPv4 protocol selectors. The observer was corrected
to accept both numeric `1` and symbolic `"icmp"`, while still rejecting every other
protocol value.
