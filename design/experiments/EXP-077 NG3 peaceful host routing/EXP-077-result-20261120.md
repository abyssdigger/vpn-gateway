## Architectural conclusion

The selected peaceful helper can provide useful Release-1 automatic host routing without
taking continuous or authoritative ownership of ordinary-host routing.

The accepted Linux realization is:

```text
local
iif managed-boundary -> main
main suppress_prefixlength 0
peaceful-helper table
ordinary main/default
```

This means explicit non-default administrator routes remain authoritative, while helper
`0.0.0.0/0` replaces only otherwise-default routing for ordinary-origin traffic. The helper
needs no runtime drift-reconciliation loop and later administrator route changes do not
control the core managed ForwardingGate.

Lifecycle ownership is bounded by protocol/signature tagging. Stop removes still-owned
helper contributions and leaves a foreign replacement untouched.
