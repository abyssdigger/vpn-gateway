## H5 — измененное базовое поколение перезапускается через absence

PASS.

Изменение базового адреса привело к последовательности:

```text
owned current
-> delete
-> confirmed absent
-> create
-> fresh exact verification
```

В этом запуске ifindex изменился с 3 на 4:

```text

EXP089_CHANGED_GENERATION_RESTART=PASS
```

Изменение ifindex является наблюдением данного запуска, а не универсальной гарантией Linux.

## Результат

```text

EXP089_CHANGED_GENERATION_RESTART=PASS

EXP089_FOREIGN_STOP_REJECTED=PASS
EXP089_RESULT=PASS
```

Для WireGuard отдельный systemd unit не является необходимым условием проверяемого базового
жизненного цикла. Достаточна прямая реализация через kernel netdevice + WireGuard state при
условии явного ownership marker, свежей проверки exact postcondition и отказа усыновлять
чужой одноименный объект.

`ifalias` в этом результате является техническим marker принадлежности, а не защитой от
администратора root. Root способен изменить любой такой kernel state; out-of-band изменение
должно рассматриваться как drift/conflict, а не как нарушение криптографической границы.

Результат не говорит, что systemd не нужен OpenVPN/OpenConnect/L2TP: daemon-based интеграции
могут сохранять собственный service lifecycle ниже того же D.001 контракта.
