## Important canonicalization consequence

The semantic compiler and exact desired-state comparison must model **observed canonical nft
JSON**, not a textual source recipe.

In particular:

```text
meta l4proto tcp + tcp sport/dport
    -> observed JSON contains tcp sport/dport
    -> separate l4proto match is removed as redundant
```

The same applies to UDP ports.

## Scope limits

- decide semantics of a port selector without an already-normalized transport protocol;
- select final REJECT realization;
- authorize mutation.

accepted as product input.
