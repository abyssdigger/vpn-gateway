# VPN-GATE NG3 — документация текущей разработки

[English version](../en/README.md)

Эти страницы относятся к текущей линии разработки NG3 в точной ревизии репозитория, содержащей их. Они не описывают и не расширяют выпущенную версию 0.1.0. Документация выпуска остаётся в собственном замороженном дереве.

## Охват
